
# Neural Network  🧠

A small neural network built from scratch with **Python + NumPy** to understand how neural networks actually work under the hood.

## 🎯 Goal

Build, train, and eventually deploy a neural network **without hiding the fundamentals behind frameworks**.

* [ ] Activation functions

* [ ] Gradient descent

* [ ] Model evaluation
* [ ] Deployment
* [ ] Trading-strategy research
